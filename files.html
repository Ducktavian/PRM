How your RelM file works

1

Open your file

Manage your network

Add people, interactions, and reminders as you use the app.

3

Save a backup

Download an updated copy before closing or changing devices.

RelM files use the JSON format so they can be backed up and opened on another device.

Close file?

The current file will be removed from the active session. Your data will not be saved unless you download a backup first.

Create new file?

This will replace your current data with an empty network. Save a backup first if you want to keep your current data.
